# CBAM 监测计划（Monitoring Plan）

本文件是设施层面的 **CBAM 监测计划** 模板与填写说明，用于说明监测边界、数据流、参数来源、质量控制与证据留存，既是内部作业文件，也是向核查机构说明「数据从哪来、怎么算、谁负责」的依据。

> **填写原则**：每一个进入申报的数值都必须能指回具体的原始记录（台账、发票、报关单、计量记录、化验单等）或经确认的输入。不得用行业均值、公开统计值或估算结果填补原始数据；能做的只有由已确认输入推导的派生量（单位排放、加权平均、单位换算）。
>
> 文中所有 `〔 〕` 为待设施填写的占位，本模板不预设任何设施数据。

### 2.3 边界说明

- 物料流：〔原料 → 中间产品 → 最终产品，含前体来源〕
- 能量流：〔燃料、电力、蒸汽、副产煤气，注明自产与外购、外送与放散〕
- 边界一经确定，报告期内不得随意变更；确需变更时走第 10 节变更管理。

## 7. 数据缺口与替代规则

数据缺失、损坏或不可用时，按以下优先级处理并留痕：

1. 追溯原始凭证或备份记录，恢复实际值；
2. 使用同一期间、同一过程的可验证替代数据（如相邻批次实测、供应商实测值），并说明替代理由；
3. 仍不可得时，采用适用法规允许的保守估算方法，**在报告中明确披露缺口、方法与影响**。

禁止在无任何依据的情况下填一个「看起来合理」的数值。

## 9. 记录与证据留存

留存范围至少包括：送货单、商业发票、报关单、提单、装箱单、原产地证书、材质书 / 化验单、电费与购售电凭证、计量记录、ERP 导出、生产与库存报表、碳价凭证。

- 保存方式：〔电子归档路径 / 纸质档案柜〕，按报告期与过程分类，可检索。
- 保存期限：按适用法规要求（过渡期实施细则要求至少 4 年），以较严格者为准。
- 证据链要求：前体实测值须能与批次单据对应，做到「单据—数量—排放因子」三点闭合；无法闭合的部分不得按实测值申报。
